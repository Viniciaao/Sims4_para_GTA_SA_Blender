# Instalação rápida

Veja [docs/instalacao.md](docs/instalacao.md) para o guia completo.

1. Instale DragonFF 1.1.0: https://extensions.blender.org/add-ons/dragonff/
2. Baixe `Sims4_para_GTA_SA_Blender_Addon_v1.0.8.zip` em [Releases](https://github.com/Viniciaao/Sims4_para_GTA_SA_Blender/releases)
3. No Blender: `Edit → Preferences → Add-ons → Install from Disk…` → selecione o ZIP → ative
4. No Viewport 3D pressione **N** → aba **Sims 4 -> SA**

Pronto!
